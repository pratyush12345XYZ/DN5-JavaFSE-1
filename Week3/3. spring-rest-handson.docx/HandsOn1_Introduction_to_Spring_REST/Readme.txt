---------------------------------------------------------
Objective
---------------------------------------------------------

The objective of this hands-on is to understand how a
Spring RESTful Web Service can be used to provide data
to an Angular application.

---------------------------------------------------------
Concepts Learned
---------------------------------------------------------

• Introduction to RESTful Web Services.
• Understanding the REST architecture.
• Role of Controller, Service and DAO layers.
• Using HTTP GET requests to fetch data.
• Returning Java objects as JSON responses.
• Testing REST APIs using Postman.
• Reading application data from Spring XML
  configuration.
• Integrating Spring Boot REST APIs with an
  Angular frontend.

---------------------------------------------------------
Problem Statement
---------------------------------------------------------

The Angular Employee Management application initially
uses hardcoded employee data.

The objective is to replace the hardcoded data by
calling REST APIs developed using Spring Boot.

The application will:

1. Read employee information from Spring XML.
2. Expose employee data through REST APIs.
3. Allow Angular to retrieve employee information
   dynamically.
4. Display employee details and support editing
   using REST services.

---------------------------------------------------------
Upcoming Hands-ons

3. Create REST API to fetch all departments.

5. Integrate the REST APIs with the Angular
   application.

---------------------------------------------------------
Conclusion
---------------------------------------------------------

This introductory hands-on provides an overview of
Spring REST architecture and explains how REST APIs
will replace hardcoded data by providing employee
information dynamically to the frontend application.
