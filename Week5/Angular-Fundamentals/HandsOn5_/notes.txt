1. angular.json
Contains the Angular workspace configuration like build, serve, assets, styles and project settings.

2. tsconfig.json
Base TypeScript configuration used throughout the Angular project.

3. tsconfig.app.json
TypeScript configuration specifically for compiling the Angular application.

4. package.json
Contains project information, dependencies and npm scripts.

5. src/main.ts
Entry point of the Angular application that bootstraps the application.

6. src/app/app.config.ts
Contains the standalone Angular application configuration including providers and routing.

7. src/app/app.ts
Root component of the Angular application.

8. src/index.html
Main HTML page loaded by the browser that hosts the Angular application.
