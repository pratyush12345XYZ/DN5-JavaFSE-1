======================================================================
OVERVIEW
======================================================================

This folder contains the implementation of ten exercises completed as
part of the Cognizant DN 5.0 Java FSE Deep Skilling Program under the
Spring Data JPA and Hibernate module.

The exercises were implemented through an Employee Management System
developed using Spring Boot, Spring Data JPA, Hibernate, H2 Database,
Spring Web, and Maven. The exercises progressively covered project
setup, entity mapping, repositories, CRUD operations, query methods,
pagination and sorting, entity auditing, projections, data source
configuration, and Hibernate-specific features.

The project was developed and tested using Java 17 and Spring Boot 3.x.

EXERCISE 1 – EMPLOYEE MANAGEMENT SYSTEM: OVERVIEW AND SETUP
======================================================================

Objective: To initialize the Employee Management System Spring Boot
project and configure the database connection.

Work Completed: - Created a new Spring Boot project named
EmployeeManagementSystem. - Added the required dependencies: - Spring
Data JPA - H2 Database - Spring Web - Lombok - Configured
application.properties for the H2 in-memory database. - Configured the
H2 JDBC URL, driver, username, password, and Hibernate dialect. -
Successfully started the Spring Boot application and verified the H2
database connection.

Concepts Learned: - Spring Boot project initialization - Maven

EXERCISE 2 – EMPLOYEE MANAGEMENT SYSTEM: CREATING ENTITIES
======================================================================

Objective: To define the Employee and Department JPA entities and
establish their relationship.

Work Completed: - Created the Employee entity with the following
fields: - id - name - email - department - Created the Department entity
with the following fields: - id - name - Used JPA annotations such as: -
@Entity - @Table - @Id - @GeneratedValue - Defined the relationship
between Department and Employee. - Implemented the one-to-many
relationship from Department to Employee and the corresponding
employee-to-department mapping. - Verified that Hibernate successfully
recognized the entity mappings.

Concepts Learned: - JPA entities - Database table mapping - Primary key
generation - Entity relationships - One-to-many and many-to-one mappings
